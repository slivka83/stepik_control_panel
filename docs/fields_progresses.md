# Поля прогресса (raw\_progress)

Всего полей: 10. Отметь Да/Нет в колонке Sync.

| # | Поле API | Тип | Sync | Описание |
| --- | --- | --- | --- | --- |
| 1 | id | text | да | ID прогресса (→ progress\_id) |
| 2 | cost | integer | да | макс баллы |
| 3 | is\_attempted | boolean | да | попытка была |
| 4 | is\_exam\_mode | boolean | да | экзамен |
| 5 | is\_passed | boolean | да | пройдено |
| 6 | last\_viewed | integer | да | последний просмотр (unix) |
| 7 | n\_steps | integer | да | всего шагов |
| 8 | n\_steps\_attempted | integer | да | шагов с попыткой |
| 9 | n\_steps\_passed | integer | да | пройденных шагов |
| 10 | score | numeric | да | баллы |
